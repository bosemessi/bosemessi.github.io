A few small browser games I've built. All run peer-to-peer in your browser — no accounts, no backend. The host shares an invite link with friends.

- [Connect 4](https://bosemessi.github.io/connect4-personal/) — classic two-player tile-drop. Up to 2 players.
- [Chinese Checkers](https://bosemessi.github.io/chinese_checkers_personal/) — 2–6 players over a star board.
- [Pictionary](https://bosemessi.github.io/pictionary_personal/) — draw, guess, score. 2–8 players.
- [Collaborative Jigsaw](https://bosemessi.github.io/puzzle_personal/) — solve a puzzle together. 1–8 players.
